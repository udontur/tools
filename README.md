# Hadrian's Tools
A collection of tools I've made over the years to make my life a little easier.

## AI Usage (For Horizons)
AI (OpenCode + Kimi 2.6 + OpenAget + Skills) is being used as an assistant when I have no idea how to
- Fix a bug: The AI tells me what's wrong, suggests ways to fix it, and occassionally implements the code which I use it as a reference to edit or rewrite the original code.
- Code something: The AI suggests me how to code it up. It never generates code and implements it for me. If I absolutely can't figure it out, I do ask it to generate code in a separate file as a reference, which is quite rare.
